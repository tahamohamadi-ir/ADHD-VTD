# پوشه `models/narrative`

این پوشه مدل‌های مربوط به خلاصه‌سازی یا narrative generation را نگه می‌دارد.

## کاربرد احتمالی

در فاز output، بعد از اجرای SQL و دریافت نتیجه معتبر، می‌توان از مدل narrative برای ساخت توضیح یا خلاصه استفاده کرد. این لایه نباید عدد یا نتیجه‌ای بسازد که در query result وجود ندارد.

## نکته فنی

برای دامنه mental health، narrative باید محافظه‌کار باشد و disclaimer پژوهشی/غیربالینی را رعایت کند. خروجی narrative نباید تشخیص پزشکی یا توصیه درمانی تولید کند.
