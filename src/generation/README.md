# پوشه `src/generation` (SQL Generation Layer)

این لایه وظیفه ساخت پرومپت‌های بهینه، فراخوانی مدل‌های زبانی محلی (LLM) و تحلیل خروجی‌های آن‌ها را بر عهده دارد.

## فایل‌ها

- **`local_llm.py`:** پیاده‌سازی اصلی فراخوانی مدل با استفاده از `llama-cpp-python`. این بخش از **شتاب‌دهی سخت‌افزاری GPU (CUDA)** پشتیبانی می‌کند که منجر به افزایش سرعت ۱۲ برابری شده است.
- **`prompt_builder.py`:** ترکیب مفاهیم سوال، طرحواره دیتابیس (DDL) و مثال‌های Few-shot با استفاده از تمپلیت‌های Jinja2.
- **`output_parser.py`:** استخراج دقیق داده‌های JSON و کدهای SQL از پاسخ مدل. این ماژول تضمین می‌کند که خروجی مدل با فرمت مورد انتظار گراف مطابقت داشته باشد.
- **`prompts/`:** شامل تمپلیت‌های تخصصی برای تولید کوئری، اصلاح خطاها (Repair) و پاسخ‌دهی به کاربر.

## ویژگی‌های کلیدی (فاز ۵)
✅ **شتاب‌دهی GPU:** بارگذاری لایه‌های مدل روی حافظه گرافیک (VRAM) برای پاسخ‌دهی زیر ۱۰ ثانیه.
✅ **فرمت JSON اجباری:** استفاده از گرامر (LlamaGrammar) برای تضمین اینکه مدل فقط خروجی JSON معتبر تولید کند.
✅ **تمپلیت‌های آماری:** آموزش مدل در پرومپت برای محاسبه صحیح درصدها و میانگین‌ها روی داده‌های سلامت.

*نکته: این لایه فقط تولیدکننده کاندیدا است و خروجی آن پیش از اجرا باید توسط `src/sql_validation` تایید شود.*
