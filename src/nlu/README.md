# پوشه `src/nlu` (Persian Natural Language Understanding)

این لایه وظیفه درک و استانداردسازی زبان طبیعی فارسی را بر عهده دارد. هدف نهایی NLU تبدیل یک سوال خام و احتمالا محاوره‌ای به یک نیت (Intent) و مجموعه‌ای از واژگان کلیدی (Terms) است که برای لایه تولید SQL قابل فهم باشد.

## فایل‌ها

- **`persian_normalizer.py`:** قلب تپنده پردازش فارسی؛ اصلاح ی/ک، نیم‌فاصله، حذف اعراب و یکسان‌سازی کاراکترهای عربی.
- **`intent_classifier.py`:** موتور تصمیم‌گیری که مشخص می‌کند سوال کاربر آماری است (`rate_query`) یا نیاز به شفاف‌سازی دارد (`ambiguous`).
- **`term_extractor.py`:** استخراج موجودیت‌ها و مفاهیم کلیدی (مانند «افسردگی»، «معدل») برای مراحل بعدی.
- **`number_normalizer.py`:** تبدیل تمام اعداد فارسی و متنی به فرمت انگلیسی استاندارد برای محاسبات.
- **`date_normalizer.py`:** استخراج و تبدیل تاریخ‌های شمسی به بازه‌های قابل کوئری (در حال توسعه).

## دستاوردها (فاز ۱ تا ۳)
✅ **نرمال‌سازی ۱۰۰٪:** تمام ورودی‌ها پیش از ورود به گراف LangGraph کاملاً تمیز می‌شوند.
✅ **تشخیص نیت هوشمند:** سیستم سوالات آماری پیچیده را از سوالات ساده بازیابی اطلاعات تشخیص می‌دهد.
✅ **یکپارچگی با گراف:** نودهای `normalize_input` و `classify_intent` مستقیماً از قابلیت‌های این پوشه استفاده می‌کنند.

## نکته فنی
در زبان فارسی، نرمال‌سازی صرفاً یک مرحله آرایشی نیست؛ بلکه پایه و اساس پایداری کل سیستم است. بدون نرمال‌سازی صحیح، جستجوی مفاهیم در دیتابیس با شکست مواجه خواهد شد.
