# پوشه `src/schema` (Schema Grounding Layer)

این لایه نقش «نقشه راه» را برای مدل زبانی ایفا می‌کند. وظیفه اصلی این بخش، ترجمه مفاهیم ذهنی کاربر به ستون‌ها، جداول و روابط واقعی موجود در دیتابیس است تا از توهم (Hallucination) مدل جلوگیری شود.

## فایل‌ها

- **`schema_linker.py`:** وظیفه اصلی این ماژول پیدا کردن نزدیک‌ترین ستون‌ها و جداول به کلمات کلیدی کاربر است.
- **`query_planner.py`:** تبدیل نیت کاربر و موارد شناسایی شده به یک طرح اولیه (QIR) که به مدل زبانی می‌گوید دقیقاً چه چیزی را باید کوئری کند.
- **`schema_registry.py`:** مخزن مرکزی تمام اطلاعات مربوط به ساختار دیتابیس که از فایل‌های JSON در `data/schema` تغذیه می‌شود.
- **`concept_registry.py`:** نگاشت مفاهیم انتزاعی (مانند «افسردگی») به ستون‌های فنی (مانند `phq9_score`).
- **`join_path_finder.py`:** پیدا کردن مسیرهای صحیح اتصال جداول بر اساس روابط کلید خارجی.

## دستاوردها (فاز ۳ و ۴)
✅ **اتصال مفاهیم (Grounding):** مدل زبانی دیگر ستون‌های خیالی نمی‌سازد، زیرا تمام ستون‌های مجاز توسط این لایه به آن دیکته می‌شود.
✅ **پشتیبانی از جستجوی فازی:** استفاده از الگوریتم‌های شباهت متنی برای درک کلماتی که دقیقاً با نام ستون یکی نیستند.
✅ **ساختار QIR:** تولید خروجی استاندارد که در گراف LangGraph برای ساخت پرومپت نهایی استفاده می‌شود.

## نکته فنی
در پروژه ADHD-VTD، ستون‌های آماری و سلامت بسیار حساس هستند. این پوشه تضمین می‌کند که برای سوالی در مورد «ریسک افسردگی»، حتماً ستون صحیح انتخاب شده و روابط بین جداول (Join) به درستی برقرار شود.
