# پوشه `data/audit`

این پوشه گزارش‌های کنترل کیفیت داده و اسکیمای پروژه را نگه می‌دارد.

## فایل‌های نمونه

- گزارش freeze اسکیمای دیتابیس.
- گزارش alignment metadata.
- گزارش audit دیتاست ۴۰۰/۵۰۰ نمونه.
- خروجی smoke test محیط.

## نکته فنی

این فایل‌ها شواهد reproducibility هستند. وقتی پروژه قرار است research-grade باشد، فقط کد کافی نیست؛ باید نشان داده شود داده، schema و SQLهای gold واقعاً قابل اجرا و هم‌راستا هستند.
