# پوشه `data/questions/full`

این پوشه بسته‌های کامل‌تر دیتاست را نگه می‌دارد؛ از جمله نسخه‌های merge شده، validated و package شده.

## کاربرد

- ساخت splitهای train/dev/test.
- audit کامل‌تر کیفیت SQLها.
- تحلیل پوشش intentها، ستون‌ها، جداول و الگوهای پرسشی.

## نکته فنی

فایل‌های full معمولاً منبع upstream هستند. اگر از آن‌ها split جدید ساخته می‌شود، بهتر است script، seed و نسبت split ثبت شود تا ارزیابی قابل بازتولید بماند.
