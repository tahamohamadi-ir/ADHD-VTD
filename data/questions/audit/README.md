# پوشه `data/questions/audit`

این پوشه داده‌ها و خروجی‌های مربوط به audit دستی و مرحله‌ای پرسش‌ها را نگه می‌دارد.

## کاربرد

- بررسی دستی کیفیت question/SQL.
- ثبت نتیجه اجرای gold SQL.
- ساخت summary برای Phase 0 و milestoneها.

## نکته فنی

Audit به پروژه کمک می‌کند قبل از اضافه کردن LLM مطمئن شود دیتاست، اسکیمای دیتابیس و SQLهای مرجع با هم سازگارند. بدون این مرحله، خطای مدل با خطای داده قاطی می‌شود.
