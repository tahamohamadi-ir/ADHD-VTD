# پوشه `data/questions`

این پوشه دیتاست پرسش‌ها را بر اساس نقش آموزشی و ارزیابی جدا می‌کند.

## زیرپوشه‌ها

- `train/`: نمونه‌های آموزشی یا توسعه‌ی prompt و retrieval.
- `dev/`: مجموعه توسعه برای تنظیم ruleها و ارزیابی سریع.
- `test/`: مجموعه آزمون نهایی که نباید برای تنظیم سیستم overfit شود.
- `full/`: بسته‌های کامل‌تر دیتاست، مثل مجموعه ۴۰۰/۵۰۰ نمونه.
- `special/`: نمونه‌های خاص مثل ambiguity، safety، no-SQL و رفتارهای edge case.
- `audit/`: نمونه‌ها و گزارش‌های audit دستی و phaseهای کنترل کیفیت.

## نکته فنی

وجود splitهای جدا باعث می‌شود توسعه‌ی سیستم قابل ارزیابی بماند. اگر ruleها یا promptها با `test/` تنظیم شوند، عدد نهایی دیگر معیار واقعی generalization نیست.

## قرارداد داده

نمونه‌ها معمولاً شامل پرسش، SQL مرجع، برچسب intent، metadata و اطلاعات ارزیابی هستند. loader اصلی در `src/evaluation/dataset_loader.py` تلاش می‌کند فرمت‌های JSON و JSONL را به یک ساختار یکنواخت normalize کند.
