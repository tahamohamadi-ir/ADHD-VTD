# پوشه `data/questions/special`

این پوشه نمونه‌هایی را نگه می‌دارد که صرفاً question-to-SQL ساده نیستند.

## نمونه‌های معمول

- پرسش‌های ambiguous که باید clarification بگیرند.
- درخواست‌های unsafe یا خارج از دامنه.
- پرسش‌های رفتاری و no-SQL.
- edge caseهای مربوط به زبان فارسی، محاوره، اعداد، تاریخ و حساسیت داده.

## نکته فنی

سیستم خوب فقط SQL درست تولید نمی‌کند؛ باید بداند چه زمانی نباید SQL تولید کند. این پوشه برای اندازه‌گیری همان قابلیت است.
