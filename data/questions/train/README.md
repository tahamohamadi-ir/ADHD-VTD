# پوشه `data/questions/train`

این پوشه split آموزشی پرسش‌ها را نگه می‌دارد. از این داده می‌توان برای ساخت few-shot، تنظیم retrieval، استخراج الگوها و توسعه‌ی ruleهای اولیه استفاده کرد.

نکته مهم این است که کیفیت train خوب، جایگزین validation مستقل نیست. تغییرات سیستم باید روی `dev/` بررسی و در نهایت روی `test/` گزارش شود.
