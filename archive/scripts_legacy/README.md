# پوشه `archive/scripts_legacy`

این پوشه scriptهای legacy را نگه می‌دارد: bootstrapهای قدیمی، patchهای موقت، تست‌های دستی phaseهای قبلی، دانلود مدل و validationهای اولیه.

## نکته فنی

این scriptها ممکن است با ساختار فعلی پروژه، مسیرهای جدید یا schema فعلی هماهنگ نباشند. اگر لازم شد یکی از آن‌ها دوباره استفاده شود، بهتر است منطقش به `scripts/` فعلی منتقل و با README/تست جدید مستند شود.
