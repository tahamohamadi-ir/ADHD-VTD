# پوشه `archive/src`

این پوشه backupهای قدیمی source code را نگه می‌دارد.

## محتوا

- `config_backup_phase0/`: نسخه پشتیبان تنظیمات و مسیرها در Phase 0.
- `core_backup_phase0/`: نسخه پشتیبان مدل‌های core، enumها و exceptionها در Phase 0.

## نکته فنی

کد فعال پروژه در `src/` ریشه است. این پوشه فقط برای audit تاریخی و مقایسه تغییرات نگه داشته شده است.
