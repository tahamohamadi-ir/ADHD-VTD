# پوشه `scratch`

این پوشه برای یادداشت‌ها، خروجی‌های موقت و آزمایش‌های کوتاه‌مدت است.

## قانون استفاده

هیچ منطق production، dataset canonical یا گزارش paper نباید فقط اینجا وجود داشته باشد. اگر چیزی مفید شد، باید به پوشه مناسب منتقل شود: کد به `src/` یا `scripts/`، گزارش به `results/` یا `docs/`، داده به `data/`.
